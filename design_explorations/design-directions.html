Three directions for the similarity search tool

Same product, same fixture data — three different bets on how a DJ finds the next record. Built only from the product brief, with no reference to any existing implementation.

Console — dense, utilitarian, DJ-booth usable

Console is built for the booth, not the couch: dense rows, monospace data, and a full-spectrum Camelot wheel mean the next record can be found at a glance under stage lighting, one thumb on a phone propped against the mixer. Compatibility is answered on the wheel itself — select a key and its A/B partner and neighbors light up — so a DJ never opens a filter to check whether two records will mix. Score shows as a short segmented bar before it shows a percentage, because at this density eight results in the high 80s should look like what they are: nearly tied. The trade-off is warmth — this is an instrument panel, not a place to linger.

Liner Notes — editorial, spacious

Liner Notes treats a result list like a crate-digger's shortlist, not a database dump: serif display type stands in for the missing album art, and every match opens with a word — Best match, Close match — before it ever shows a digit, because the brief is explicit that 92% and 86% are closer than the numbers suggest. Compatible keys get a quiet ochre mark and a line of explanation rather than a loud badge, fitting a page built for browsing at leisure rather than deciding in a hurry. The Camelot wheel is drawn like a diagram in a liner-notes booklet — thin ink lines on stone paper — a reference chart, not a control surface. This direction optimizes for trust and pace over speed of scanning.

Pulse — bold, flat-color, built for chained discovery

Pulse is for a phone in someone's hand at a party, chaining one track into the next for fun: flat, saturated color takes over the job album art usually does, with every result getting a swatch generated from its key and score tier so the list has visual texture with zero images. The same twelve-hue system used across those swatches becomes the hero of the key-browser wheel, so the color language is consistent rather than decorative — learn it once on the wheel and it explains the whole app. Compatibility uses one dedicated lime accent everywhere, kept apart from the violet brand color, so "this will mix" is never confused with "this is selected." It trades density for momentum — built to be tapped through quickly, not studied.
